# Healthcare Data Analysis Assignment Using Excel

## Overview
This assignment focuses on cleaning, transforming, analyzing, and visualizing healthcare data using Microsoft Excel and Power Query.

## Tools Used
- Microsoft Excel
- Power Query
- VLOOKUP
- PivotTables
- PivotCharts

## Data Cleaning and Transformation
- Handled missing values using appropriate methods.
- Standardized text values and corrected data types.
- Split customer names into First Name, Title, and Last Name.
- Created Weight Status based on BMI.
- Created Diabetes Status based on HBA1C.
- Combined year, month, and date into a date column.
- Calculated patient age as of 8 June 2023.
- Combined three tables using Customer ID and VLOOKUP.

## Data Analysis and Visualization
Created PivotTables and charts to analyze:

1. Cancer history among smokers and non-smokers.
2. Major surgeries and average HBA1C based on transplant history.
3. Healthcare charges by weight status and diabetes status.
4. Average healthcare charges by hospital tier and state.
5. Relationships between age, BMI, and HBA1C.
6. The relationship between age and healthcare charges.

## Dashboard
Created an interactive dashboard with KPI cards and charts to present key findings.

Added slicers for:
- Weight Status
- Diabetes Status

## Conclusion
This assignment provided practical experience in data cleaning, data transformation, analysis, and visualization using Excel and Power Query.
